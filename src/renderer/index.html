Welcome

This sets up YouTube for your family so it only shows channels you approve.

It takes about 5 minutes and only needs to be done once. A parent should do this part.

Choose a parent PIN

You'll use this PIN to add or remove channels. Pick 4 to 8 numbers your child doesn't know.

Get a free YouTube key

The app needs a free key from Google to load videos. You only do this once.

  1. Open Google Cloud and sign in with your normal Google account. If asked, agree to the terms and create a project (any name, for example "Family YouTube").
  2. Turn on the YouTube API. On this page, press the blue Enable button.
  3. Create the key. On this page, press + Create credentials, then API key. Copy the key it shows (it starts with "AIza").
  4. Paste the key here and press Check.

It's free. Google doesn't charge for this unless you add billing yourself.

All set

Next, you'll add your approved channels from the parent area. That arrives in the next version.

To open the parent area later: press Ctrl + Shift + P, or press and hold the round letter in the top-right corner for 3 seconds.
